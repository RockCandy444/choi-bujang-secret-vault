헤임달 사용 안내

「다시 조회」로 현재 PC의 값을 읽습니다. 자동 조회는 기본으로 꺼져 있고, 켜면 이 화면이 보이는 동안에만 실행됩니다. 10초 이내의 반복 조회에는 같은 실측 결과를 사용합니다.

값을 읽는 방법

  • CPU: 약 400ms 동안 모든 논리 CPU의 누적 시간 차이로 계산합니다.
  • 메모리: OS 전체 메모리에서 사용 가능 메모리를 뺀 값입니다. 작업 관리자의 집계 범위·측정 시점과 다를 수 있습니다.
  • 디스크: 시스템 드라이브의 사용 가능 공간입니다. GB가 아닌 GiB(1,024³바이트)로 표시합니다.
  • 방화벽: Domain·Private·Public 프로필의 설정 값입니다. 실제 방어 효과나 현재 활성 프로필 판정이 아닙니다.
  • Windows 기록: 최근 24시간 System·Application의 경고·오류를 채널별 최대 2,000건 읽습니다. 상한에 걸리면 일부 집계로 표시합니다.
  • 네트워크: 루프백을 제외한 주소 구성 인터페이스 수입니다. 인터넷 연결·통신 성공을 시험하지 않습니다.

확인한 범위만 표시합니다

읽지 못한 값은 0이나 예시로 채우지 않습니다. SDP의 어댑터 설정은 실제 접속 검증과 구분합니다. 예제 실행에서도 이 대시보드의 PC 값은 현재 PC 실측이며, 기존 보안 Agent의 예제 자료와 별개입니다.

조회 이력은 브라우저 메모리에만 남습니다. 이름·IP·MAC·이벤트 본문은 수집하지 않으며 외부 API나 AI로 보내지 않습니다. 설정 변경·조치 집행은 하지 않습니다.

기존 제공 기능: 보안 Agent와 연결 진단. 학생 추가 기능: PC 조회·관제 화면·추이·오류 안내. 이 화면은 프로젝트 폴더에서 실행하는 완성본이며 설치형 앱 검증은 포함하지 않습니다.
