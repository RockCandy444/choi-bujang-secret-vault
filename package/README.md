## 새 프로젝트에 배포

1. Vercel에서 **새 프로젝트**를 만들고 위 GitHub 저장소를 연결합니다. 쓰던 프로젝트의 환경변수나 설정을 복사했다고 가정하지 마세요.
2. 필요한 환경변수의 **이름**을 위 목록과 대조하고, 실제 값은 Vercel의 비밀 입력란에만 넣습니다. 화면을 캡처할 때 값은 가리세요.
3. 저장소의 `vercel.json`에 적힌 빌드 명령과 공개 폴더를 확인하고 배포합니다. 시작 틀은 Vercel이 제공하는 저장소·커밋·배포 URL 정보가 없으면 일반 `npm run build`가 실패합니다.
4. 배포가 완료되면 새 주소로 첫 화면을 엽니다. 실제 기능과 로그인·거절 동작도 별도로 확인합니다.
5. 환경변수 이름을 넣는 화면, 배포 완료 화면, 첫 화면을 `package/self-check/P7-1.png`부터 `P7-3.png`까지 캡처하고 `SELF-CHECK.md`에 결과를 적습니다.
